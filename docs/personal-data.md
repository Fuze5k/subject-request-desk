# Personal data stored by Subject Request Desk

For the Privacy and Security tab and the personal data reporting review.

| Data | Where | Why | Removed |
|---|---|---|---|
| Atlassian account id (opened, decided, closed by) | Forge storage, request record and history | Audit history | On account closure (reported via `privacy.reportPersonalData`, weekly check) |
| Subject label and search terms typed by the officer | Forge storage | To run the search | When the request is closed |
| Hit titles | Forge storage | Review | When the request is closed |
| Reply draft | Forge storage | Drafting | When the request is closed |
| Hit references (key/id, source, container, url), decisions, counts | Forge storage | Proof for the audit | Kept with the record |

No data leaves Atlassian. No egress is declared in the manifest.
